# Project Name

Nuxt 4 project deployed via Cloudflare Pages.

## Setup

Install dependencies:

npm install

Run dev server:

npm run dev

Build:

npm run build

Preview:

npm run preview

## Deployment

Auto-deploy via Cloudflare Pages on push to main branch.

## Environment Variables

Create .env file:

NUXT_PUBLIC_SITE_URL=

## Stack

- Nuxt 4
- Nuxt Content
- Cloudflare Pages
